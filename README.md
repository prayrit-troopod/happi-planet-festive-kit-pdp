# Happi Planet: Festive Cleaning Kit PDP redesign

Design preview of the Festive Cleaning Kit product page. Static snapshot for review, not the live store.

Changes from the original page:

- "What's in the box" gift-box card under the price: the six products pop out of the kit box when it scrolls into view.
- Add To Cart button under the box, plus the sticky bar's button switched from Sold Out to Add To Cart. Both link to the live store cart with one kit.
- Eco Friendly / Non Toxic / Plant Based shown as a USP row instead of two dropdowns.
- Before/After slider rebuilt: labels match the photos, starts off-centre with one hint sweep, drag or tap anywhere.
- Ingredients moved out of the dropdown into a "Powered by nature" section.
- FAQs moved out of the dropdowns into a full-width section above Customer Reviews (first question's title/answer split fixed, last answer completed).
- Special Offer block removed; remaining dropdowns reordered and closed by default.

Notes:

- The new elements' code is in `index.html` under the `tp-` class prefix.
- Third-party analytics, pixels and checkout/login SDKs from the original page are disabled in this preview.
- The ingredient one-liners are draft copy and need the brand's sign-off.
